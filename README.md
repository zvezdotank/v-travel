# V-travel — лендинг турагентства

Статичный сайт без сборки и без бэкенда. Открывается как `index.html`,
заливается на любой хостинг (GitHub Pages, Netlify, обычный nginx) простым копированием папки.

```
index.html          главная
turciya/ egipet/    страницы направлений — СОБИРАЮТСЯ, вручную не править
tailand/ vietnam/
scripts/build_pages.py   генератор страниц направлений и sitemap
css/styles.css      дизайн-система и стили главной
css/pages.css       стили страниц направлений
js/main.js          меню, анимации, сборка ссылок в Telegram
assets/img/         фотографии
```

## Страницы направлений собираются, а не пишутся руками

Четыре страницы отличаются только содержимым, поэтому шапка, подвал и разметка
описаны один раз в `scripts/build_pages.py`. Там же лежат данные: курорты,
сезонность, авторские программы и вопросы.

```bash
python3 scripts/build_pages.py
```

Команда перезаписывает `turciya/index.html` и остальные три, а также `sitemap.xml`.
Правки прямо в этих html пропадут при следующей сборке — меняйте данные в скрипте.

## Вся конверсия ведёт в два места

Заявок на сервер сайт не отправляет — некуда и незачем. Каждая кнопка ведёт
либо на `tel:`, либо в Telegram с уже вписанным текстом заявки.

## Что менять при смене контактов

| Что | Где |
|---|---|
| Телефон | `index.html`, поиск по `+998903172288` (10 мест) и по отображаемому `+998 90 317-22-88` |
| Telegram менеджера | `js/main.js`, константа `TG_USER` вверху файла, плюс `t.me/vtour_travel` в `index.html` |
| Канал с горящими турами | `index.html`, `t.me/vtour_deals` в финальном блоке |
| Часы работы | `index.html`, строки с `09:00–21:00` |

## Горящие туры

Карточки в секции `#hot` заданы вручную в разметке. У кнопки «Забронировать»
есть атрибут `data-tour` — его текст подставляется в сообщение Telegram,
поэтому при смене цены или дат правьте и заголовок карточки, и `data-tour`.

## Форма подбора

Собирает ответы в одно сообщение и открывает чат с менеджером.
Если браузер заблокировал всплывающее окно, под кнопкой появляется подсказка
с телефоном — форма не «молчит».

## Метрики

На всех целевых кнопках стоит `data-goal="call"` или `data-goal="telegram"`.
Когда подключите аналитику, цели вешаются одним обработчиком по этому атрибуту.

## Аккуратно с производительностью

Фон героя намеренно статичный. Бесконечная анимация под слоем `mix-blend-mode`
заставляет браузер пересчитывать смешивание каждый кадр и заметно греет слабые
телефоны — если будете добавлять движение, не делайте это поверх дуотон-слоя.

## Картинки

`assets/img/Новая папка с объектами/` — сгенерированные изображения из другого
проекта (робот, планшет), сайтом не используются. Можно удалить.
